# OpenCAT â€” Database Schema

**Version:** 1.1 (Phase 5 Track D)
**Engine:** PostgreSQL 16 (required â€” uses `pg_trgm`, `JSONB`)
**Note:** This schema extends the API schema defined in `planning/phase-5/db-centric-design.md`. All tables from that schema are included here with studio-specific additions (users, teams, settings, MT configs).

### UUID Strategy

UUID primary keys are assigned by **Eloquent `HasUuids`** in PHP before the `INSERT` â€” not by PostgreSQL's `gen_random_uuid()`. This means:

- No `pgcrypto` extension required (removed)
- Eloquent knows the model's `id` before it hits the database â€” safe to use in relationships and events before `save()`
- `HasUuids` internally uses `Str::orderedUuid()`, which generates time-prefixed UUIDs (UUIDv1-based, monotonically increasing per second) â€” significantly better B-tree index locality than random v4 UUIDs, reducing page splits under write load

In migrations, UUID PKs are declared as:
```php
$table->uuid('id')->primary();
```
Not `UUID PRIMARY KEY DEFAULT gen_random_uuid()`. The SQL reference blocks below omit the `DEFAULT` clause to reflect this â€” the database never generates a UUID on its own.

## Prerequisites

Run once on a fresh database before migrations:

```sql
CREATE EXTENSION IF NOT EXISTS pg_trgm;  -- fuzzy TM search (D32)
-- pgcrypto is NOT required: UUIDs are generated by Eloquent HasUuids, not PostgreSQL
```

Laravel migrations run this via a dedicated migration that runs first.


### `translation_memories`

One row = one TM resource linked to a project (or global). The actual TM entries are in `tm_units` (see below). This metadata table lets the UI list, name, and describe TMs.

```sql
CREATE TABLE translation_memories (
    id           UUID         PRIMARY KEY  -- assigned by Eloquent HasUuids
    team_id      UUID         NOT NULL REFERENCES teams(id) ON DELETE CASCADE,
    project_id   UUID         REFERENCES projects(id) ON DELETE CASCADE,
    -- NULL = global TM (shared across all projects in the team)
    name         VARCHAR(255) NOT NULL,
    source_lang  VARCHAR(20)  NOT NULL,
    target_lang  VARCHAR(20)  NOT NULL,
    entry_count  INT          NOT NULL DEFAULT 0,   -- denormalized, updated on insert/delete
    is_global    BOOLEAN      NOT NULL DEFAULT false,
    created_at   TIMESTAMPTZ  NOT NULL DEFAULT now(),
    updated_at   TIMESTAMPTZ  NOT NULL DEFAULT now()
);

CREATE INDEX tm_team_id     ON translation_memories(team_id);
CREATE INDEX tm_project_id  ON translation_memories(project_id);
```

### `tm_units` *(the actual TM content â€” `PostgresTranslationMemory`, D32)*

**Table name is `tm_units` â€” hardcoded in `opencat/translation-memory/src/PostgresTranslationMemory.php`.** Do not rename. The studio migration must use this exact name.

The columns below are derived directly from the framework's INSERT and SELECT statements â€” not invented for this document.

```sql
CREATE TABLE tm_units (
    id                      BIGSERIAL    PRIMARY KEY,
    tm_id                   UUID         NOT NULL REFERENCES translation_memories(id) ON DELETE CASCADE,
    source_lang             VARCHAR(20)  NOT NULL,
    target_lang             VARCHAR(20)  NOT NULL,
    source_text             TEXT         NOT NULL,
    -- Plain text with {N}/{/N}/{N/} tag placeholders stripped (human-readable)
    target_text             TEXT         NOT NULL,
    source_segment          TEXT         NOT NULL,
    -- JSON-serialised Segment including InlineCodes (SegmentSerializer::serialize)
    -- Used to reconstruct the full Segment on lookup (tags intact)
    target_segment          TEXT         NOT NULL,
    source_text_normalized  TEXT         NOT NULL,
    -- Lowercased, NFC-normalised, whitespace-collapsed source_text
    -- pg_trgm index is on THIS column, not source_text
    created_at              TIMESTAMPTZ  NOT NULL,
    last_used_at            TIMESTAMPTZ,
    -- Updated on every successful lookup hit (touchLastUsedAt)
    created_by              VARCHAR(255),
    -- Optional: translator name or tool identifier
    metadata                JSONB        NOT NULL DEFAULT '{}',
    -- e.g., {"origin": "human", "client": "ACME Corp", "domain": "legal"}

    -- ON CONFLICT target used by store() for upsert (update target if source already exists)
    UNIQUE (tm_id, source_lang, target_lang, source_text_normalized)
);

-- GIN trigram index for pg_trgm Stage 1 pre-filter (D32)
-- Must be on source_text_normalized, not source_text
CREATE INDEX tm_units_source_trgm
    ON tm_units USING GIN (source_text_normalized gin_trgm_ops);

CREATE INDEX tm_units_tm_id ON tm_units(tm_id);
```

### `glossaries`

One row = one glossary linked to a project (or global). Actual terms are managed by `opencat/terminology` via a **SQLite file** stored at `storage/app/glossaries/{team_id}/{id}.db`. This table is metadata only.

```sql
CREATE TABLE glossaries (
    id           UUID         PRIMARY KEY  -- assigned by Eloquent HasUuids
    team_id      UUID         NOT NULL REFERENCES teams(id) ON DELETE CASCADE,
    project_id   UUID         REFERENCES projects(id) ON DELETE CASCADE,
    -- NULL = global glossary
    name         VARCHAR(255) NOT NULL,
    source_lang  VARCHAR(20)  NOT NULL,
    target_lang  VARCHAR(20)  NOT NULL,
    term_count   INT          NOT NULL DEFAULT 0,   -- denormalized
    sqlite_path  TEXT         NOT NULL,
    -- storage/app/glossaries/{team_id}/{id}.db â€” managed by SqliteTerminologyProvider
    is_global    BOOLEAN      NOT NULL DEFAULT false,
    created_at   TIMESTAMPTZ  NOT NULL DEFAULT now(),
    updated_at   TIMESTAMPTZ  NOT NULL DEFAULT now()
);

CREATE INDEX glossaries_team_id    ON glossaries(team_id);
CREATE INDEX glossaries_project_id ON glossaries(project_id);
```

```sql
CREATE TABLE project_files (

    export_path     TEXT,

    updated_at      TIMESTAMPTZ  NOT NULL DEFAULT now()
);

CREATE INDEX project_files_project_id ON project_files(project_id);
CREATE INDEX project_files_status     ON project_files(status);
```

### `segments` *(core translation data â€” PostgresSegmentStore, D30)*

```sql
CREATE TABLE segments (
    id               UUID         PRIMARY KEY  -- assigned by Eloquent HasUuids
    file_id          UUID         NOT NULL REFERENCES project_files(id) ON DELETE CASCADE,
    project_id       UUID         NOT NULL REFERENCES projects(id) ON DELETE CASCADE,
    segment_number   INT          NOT NULL,
    -- 1-based order within file; determines display order
    source_text      TEXT         NOT NULL,
    -- Plain text with {N} {/N} {N/} tag placeholders (D28)
    target_text      TEXT,
    -- NULL = untranslated. Same placeholder format when tags are re-inserted.
    source_tags      JSONB        NOT NULL DEFAULT '[]',
    -- Tag map: [{"id":1,"type":"open","data":"<b>","displayText":"b"}, ...]
    target_tags      JSONB        NOT NULL DEFAULT '[]',
    status           VARCHAR(20)  NOT NULL DEFAULT 'untranslated',
    -- SegmentStatus enum values (D29):
    -- 'untranslated' | 'draft' | 'translated' | 'reviewed' | 'approved' | 'rejected'
    word_count       INT          NOT NULL DEFAULT 0,
    char_count       INT          NOT NULL DEFAULT 0,
    tm_match_percent SMALLINT,
    -- 0-100. NULL = no match attempted or no match found.
    tm_match_origin  VARCHAR(20),
    -- 'tm' | 'mt' | 'human' | 'exact' | NULL
    context_before   TEXT,        -- preceding segment source text (for TM context matching)
    context_after    TEXT,        -- following segment source text
    note             TEXT,        -- translator note attached to this segment
    locked           BOOLEAN      NOT NULL DEFAULT false,
    -- true = segment is locked by reviewer (V2). Segment saves are rejected when locked.
    created_at       TIMESTAMPTZ  NOT NULL DEFAULT now(),
    updated_at       TIMESTAMPTZ  NOT NULL DEFAULT now(),

    UNIQUE(file_id, segment_number)
);

CREATE INDEX segments_file_id         ON segments(file_id);
CREATE INDEX segments_project_id      ON segments(project_id);
CREATE INDEX segments_status          ON segments(status);
CREATE INDEX segments_file_status     ON segments(file_id, status);
-- Composite index for editor pagination: ordered fetch by file + segment number
CREATE INDEX segments_file_order      ON segments(file_id, segment_number ASC);
-- GIN trigram index for concordance search in segments
CREATE INDEX segments_source_trgm     ON segments USING GIN (source_text gin_trgm_ops);
```

### `mt_configs`

Per-user MT API keys. Keys are stored encrypted using Laravel's `encrypt()`/`decrypt()`.

```sql
CREATE TABLE mt_configs (
    id           BIGSERIAL    PRIMARY KEY,
    user_id      UUID         NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    provider     VARCHAR(20)  NOT NULL,
    -- 'deepl' | 'google'
    api_key_enc  TEXT         NOT NULL,
    -- Encrypted via Laravel encrypt(). Never store plain text.
    is_active    BOOLEAN      NOT NULL DEFAULT true,
    created_at   TIMESTAMPTZ  NOT NULL DEFAULT now(),
    updated_at   TIMESTAMPTZ  NOT NULL DEFAULT now(),

    UNIQUE(user_id, provider)
);
```
